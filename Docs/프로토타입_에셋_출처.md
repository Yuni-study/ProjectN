# 프로토타입 에셋 출처

첫 임무의 외형을 기획의 군사 SF·폐허 분위기에 맞추고, 기본 도형만 보이던 화면을 교체하기 위해 적용한 무료 모델 목록이다. 모두 Quaternius의 무료 표준 팩에서 가져왔다.

| 사용 영역 | 에셋 팩 | 적용 모델 |
| --- | --- | --- |
| 필드 구조물·데크·단말·엄폐물 | [Modular Sci-Fi MegaKit](https://quaternius.com/packs/modularscifimegakit.html) | Platform_Metal2, WallAstra/WallBand, Prop_AccessPoint |
| 캐릭터 총기·적·보급품·엄폐물 | [Sci-Fi Essentials Kit](https://quaternius.itch.io/sci-fi-essentials-kit) | Gun_Sniper, Gun_Rifle, Enemy_EyeDrone, Enemy_Trilobite, Enemy_QuadShell, Prop_Crate |
| 분대 캐릭터와 Lumen | [Ultimate Modular Women](https://quaternius.com/packs/ultimatemodularwomen.html) | SciFi, Suit, Soldier. 복장이 포함된 여성 휴머노이드 모델과 24개 애니메이션 |

모든 팩은 CC0 1.0 표준 라이선스다. 제공된 라이선스 파일은 `Assets/Resources/Art/Quaternius` 아래 보존한다. Ultimate Modular Women의 공개 배포 원본은 glTF이며, 런타임에서 Unity가 바로 불러올 수 있도록 Blender로 FBX로 변환했다. 원본 glTF와 변환된 FBX를 모두 `Assets/Resources/Art/Quaternius/UltimateModularWomen`에 보존한다.

분대에는 SciFi, Suit, Soldier 모델을 적용한다. 기본 이동은 걷기·달리기 클립으로 재생하고, 상체에는 총을 든 자세를 계속 겹쳐 적용해 이동 중에도 총을 손에 든다. 조준 입력 중에는 상체 애니메이션을 견착 조준 클립으로 전환하고, 발사 때는 사격 클립을 재생한다. 이동은 CharacterController가 담당하고 Animator의 루트 모션은 끈다. 총기는 캐릭터 루트 아래에 두고, 애니메이션 갱신 뒤 개머리판을 어깨에 맞추며 양팔 IK로 오른손 손잡이와 왼손 지지점을 유지한다. 총구는 모델의 앞쪽 끝에 배치한다. 발사마다 총과 양팔에 짧은 후퇴·들림 반동을 주고 원래 자세로 복귀한다. Morrow의 탄약 소품 연결을 제거하고 현재는 Rook과 같은 Rifle 외형을 사용한다. 무기별 전투 수치는 유지한다. 같은 리그 구조를 사용하므로 공통 Animator Controller와 상체 Avatar Mask로 세 캐릭터의 이동·무장·조준·발사 동작을 조합한다.

캐릭터 무기 포즈는 현재 프로토타입용 애니메이션 적용이다. 손가락이 손잡이를 감싸는 별도 리깅, 재장전 애니메이션, 저격총 전용 줌 포즈와 캐릭터별 고유 모션은 아직 제작하지 않았다. 보스는 QuadShell 모델을 확대해 사용하고, 전투 판정과 이동에는 기존 캡슐 충돌체를 유지한다.
