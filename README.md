# ProjectN — Surface Echo

폐허가 된 지상을 탐색하며 AI 동료들과 끊기지 않은 신호를 추적하는 3인칭 슈팅 게임입니다. 플레이어는 Sable, Morrow, Rook을 전환해 전투하고, 분대와 함께 여러 교전 구역을 통과해 통신 중계소와 보스를 만납니다.

## 프로젝트 정보

- **엔진:** Unity 6000.3.12f1
- **언어:** C#
- **플랫폼:** PC
- **입력:** 키보드·마우스
- **저장소:** [Yuni-study/ProjectN](https://github.com/Yuni-study/ProjectN)

## 실행 방법

1. Unity Hub에서 이 저장소 폴더를 프로젝트로 추가합니다.
2. Unity 6000.3.12f1로 프로젝트를 엽니다.
3. `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다.
4. 타이틀 화면에서 새 작전을 시작하거나 저장 데이터가 있으면 이어갑니다.

`SampleScene`이 빌드 진입 장면입니다. `PrototypeCombatBootstrap`이 실행 시 타이틀 메뉴를 만들고, 임무와 필드 오브젝트는 프로토타입 스크립트에서 구성합니다.

## 기본 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 이동 | 조준 |
| 마우스 왼쪽 버튼 | 사격 |
| 마우스 오른쪽 버튼 | 조준 확대 또는 저격 스코프 |
| R | 재장전 |
| 1 / 2 / 3 | Sable / Morrow / Rook 전환 |
| T / Y / U | 수동 1 / 2 / 3버스트 |
| 백틱 키 | 자동·수동 전투 전환 |
| Q | 수동 모드에서 Morrow로 전투 불능 동료 소생 |
| E | 통신 단말 등 상호작용 |
| Tab | 전투 조작 안내 표시 |
| Esc | 마우스 커서 잠금·해제 |

대화 중에는 Space 또는 Enter로 다음 대사, Left Shift로 자동 진행, Tab으로 대화 로그, Backspace로 건너뛰기를 사용할 수 있습니다. 대화 UI의 버튼으로도 같은 기능을 선택할 수 있습니다.

## 구현 범위

- 3인칭 이동, 카메라 충돌 대응, 조준·사격·재장전과 탄환·명중 피드백
- 세 캐릭터 전환과 무기별 탄창, 체력, 버스트 연계 및 스킬
- 동료 AI의 대형 이동, 표적 선택, 사격, 재장전과 엄폐 행동
- 일반 적과 보스의 공격 패턴 및 공격 예고 구역 표시
- 첫 임무의 도입 대화, 여러 교전 구역, 중계소 복구, 체크포인트 저장과 빠른 이동
- 보스 처치 후 보상 화면과 필드 자유 이동
- 대화·전투 HUD, 해상도 대응, 프로토타입 배경음과 효과음
